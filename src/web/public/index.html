              🛡️ File System Access & Workspace Sandboxing
            

            

              Autonomous models can sometimes be "snarky" and attempt to scatter files directly on your Windows Desktop. NexusRoute implements defense-in-depth protection to keep your desktop and home folder clean:
            


            

              

                1. Sandboxed Workspace Mode (Safe Default)
                

                  All file writes (write_file, patch_file) are strictly confined to the designated workspace directory (default: ./workspace). Any attempt to write outside or traverse up with ../ throws an immediate SecurityError.
                

              


              

                2. Instant Desktop Shield (blockDesktopAccess)
                

                  Direct writes to C:\Users\...\Desktop are strictly prohibited by default. Even if you switch to Trusted Mode, your Desktop remains shielded unless you explicitly toggle off the Desktop Shield switch.
                

              


              

                3. Pick or Name a Workspace Folder
                

                  You can assign any folder you want in ⚙️ Prompts & Rules Studio (e.g. ./workspace, ./projects, ./scratch, or a custom absolute folder path).
                

              


              

                4. Windows System Directory Guard
                

                  System directories (C:\Windows, System32) are permanently prohibited under all configurations, including Trusted Mode.
