🔌 Connect External Apps & MCP Tools

NexusRoute is a drop-in OpenAI-compatible proxy. Copy any snippet below to connect your everyday tools in seconds!

In Cursor Settings > Models > OpenAI API Key, set:

Base URL: http://localhost:3000/v1
API Key:  nr-live-xxxx (or any string)
Models:   auto, fast, reasoning, coding, gpt-4o
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:3000/v1",
    api_key="nr-live-xxxx"  # Or your virtual key
)

response = client.chat.completions.create(
    model="auto",
    messages=[{"role": "user", "content": "Explain quantum computing."}],
    stream=True
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")
import OpenAI from 'openai';

const openai = new OpenAI({
  baseURL: 'http://localhost:3000/v1',
  apiKey: 'nr-live-xxxx',
});

const res = await openai.chat.completions.create({
  model: 'auto',
  messages: [{ role: 'user', content: 'Hello NexusRoute!' }],
});
console.log(res.choices[0].message.content);
curl -X POST http://localhost:3000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer nr-live-xxxx" \
  -d '{
    "model": "auto",
    "messages": [{"role": "user", "content": "Ping!"}]
  }'
1. MCP clientYour coding agent or desktop AI asks what tools exist.
→
2. NexusRoute server/mcp publishes workspace, web, memory, Android and art tools.
→
3. Tool resultNexusRoute executes locally and returns a standard result to the agent.

MCP is a standard way for an AI application to discover and call tools. Add this Streamable HTTP server to an MCP-capable client:

{
  "mcpServers": {
    "nexusroute": {
      "type": "http",
      "url": "http://127.0.0.1:3000/mcp"
    }
  }
}

Endpoint: http://127.0.0.1:3000/mcp · Transport: stateless Streamable HTTP · The server remains local and workspace-scoped.
